# Hardware

This folder contains all hardware-related files for the RP2040-based PCB project.

## Structure

- /schematics → Circuit schematics
- /gerber → Manufacturing files (Gerber, BOM, PAP)
- /pictures → Photos of the PCB (screenshots, renders)

## Description

The project focuses on a minimal and compact RP2040-based PCB designed for space-constrained applications.
The core board is intended to be stable and simple, while later expansion is handled via external shields connected via pogo pins.

## Status

Currently in early development (V1 prototype stage).
